# Sky Dominion Tycoon: Operations Visibility Edition

A standalone browser-based airplane tycoon game with advanced simulation, detailed operations visibility, and workforce + fleet control.

## Run

Open `index.html` in a modern browser.

## Major systems in this update

- Collapsible/dropdown (`details`) sections across all major UI areas for easier viewing and compact mode
- Super-detailed live event log with typed entries and structured metrics
- Owned airports operations view with traffic, delays, and weather-linked operational context
- Per-region live weather board (type, wind, visibility, temperature)
- Owned flights monitor with detailed in-air telemetry (route, pax, altitude, speed, ETA, weather exposure)
- Dynamic flight lifecycle simulation (arrival, turnaround, reassignment)
- 30+ airlines in live leaderboard with continuous updates
- 360 named/customizable aircraft models and 140 named routes
- Advanced route customizer, hiring command, pilot academy, and variable simulation speeds

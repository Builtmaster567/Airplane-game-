# Sky Dominion Tycoon: Workforce Command Edition

A standalone browser-based airplane tycoon game with expanded HR management, large-scale operations, and deep simulation systems.

## Run

Open `index.html` in a modern browser.

## Major systems in this update

- Ultra-detailed hiring system with per-person employee records
- Individual workforce controls: adjust wage, change position, and train each employee
- Dedicated pilot academy and pilot-specific progression (flight hours + certifications)
- 400+ workforce feature modules integrated into progression metrics
- Department-based employee filtering and name search
- 360 named/customizable aircraft models and lifecycle controls
- 140 named routes with route viewer and route customization controls
- 100+ airports, hubs, contracts, specials, fuel economy, and world simulation
- Expanded live leaderboard with 30+ airline competitors
- Simulation speed controls (1x, 2x, 3x, 5x, 8x)
